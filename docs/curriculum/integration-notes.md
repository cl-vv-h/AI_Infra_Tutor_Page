# 课程整理与后续接入顺序

本文件是基于已盘点资料的编辑方案，不代表对应网页或补写课程已经完成。

## 本轮已完成

- 八个领域、47 个主题与每项材料的唯一主要归属。
- 182 项材料与 467 个源文件的完整清单；中英文版本合并展示，缺失翻译明确标记。
- 四条学习路线，包含入口要求、逐步阅读材料、每步目标与可选分支。
- 139 条已有站内文章路由与逐语言副本差异对照。
- 16 项源仓库明确列出的计划文件，与已有材料分开记录。
- 原文固定版本链接的提取与追溯入口；尚未逐篇归一化所有底层依赖版本。

## 发现的接入差距

共有 43 项材料没有对应的现有文章索引，其中 32 项属于正文、实验、参考或模型案例，其余是目录、图表与维护资源。主要新增内容集中在 Communication、进阶 Parallel Strategy、mHC、DSpark、GLM-5.2、GLM-5.3-Flash 和相关源码走读。

按中英文文件分别比较，358 个语言文件中：119 个与站内副本相同，157 个不同，82 个尚未收录。**这不是 157 篇过时课程的结论**：网站可能有公式、链接或排版适配，必须保留有意义的编辑，不能全量覆盖。

现有 `scripts/curriculum-index.mjs` 主要按物理目录映射分类，同一子分类内按路径排序后生成前后篇。`scripts/sync-curriculum.mjs` 会复制文件并重新生成索引；支持 Markdown、Python 和常见图片，但不包含 HTML。直接同步无法完成新的知识分类，也不会自动把六份交互图接成可访问资源。本轮未调用它。

## 下一增量：课程总览和主题入口

范围建议限制为教学目录：展示八大知识领域、四条学习路线，以及统一的主题入口。原有模型工具、Attention 图谱和性能分析工具通过相关主题链接关联，不改变其计算逻辑，也不增加首页业务模块。

一个主题入口应包含：核心问题、建议先修、原理 → 运行时 → 平台 → 实验的可用材料、源码版本提示和相关模型案例。没有材料的层次可省略；计划项明确标注，不形成失效“开始学习”链接。

第一版原型建议选择 **KV Cache** 与 **DP Attention**，因为它们跨原理、源码、平台和实验，能验证分类方式是否真正减少查找成本。审查这两个主题后，再以同一结构扩展其余主题。

此增量验收要求：

1. 所有 139 条旧文章路由继续可用；不因新目录改变 ID、收藏键或旧链接。新材料路径先纳入审核，再生成新文章入口。
2. 只给有实际来源的条目提供阅读入口；中文专有内容标明语言，不展示虚假的英文正文。
3. 导航按学习目标编排，函数地图、许可证、资源索引不充当普通下一课。
4. 主题标题、先修链接和材料链接可用键盘操作；检查移动端、返回、刷新、加载失败与重试。
5. 独立构建开关关闭后恢复原课程入口；数据和旧文章保持可用。
6. 单独提交、回退演练和 Pages 上线核验；本轮的内容映射不等于这些验收已经通过。

## 资料维护优先级

1. **版本与路由。** 对照站内差异，确定哪些为旧内容、哪些为网站适配；逐篇明确主要实现版本，保持旧链接。
2. **导航与先修。** 建立主题入口，先让已有内容能被找到；补充入门张量、dtype、layout 的短导读，连接现有详细材料。
3. **学习粒度。** 拆解上述五篇长文；为 22 份实验代码核对依赖、启动命令、输入、预期输出和验证范围。注释源码单列为参考。
4. **文档问题。** 修复基础 README 的旧路径；五篇量化正文与 Qwen3.5 Hybrid 的英文缺失单独排期。仅存在英文路径的中文注释代码不能标为英文翻译完成。
5. **真实缺口。** 16 个计划文件按知识需求逐一评估；已经由旧文或案例覆盖的部分优先关联，不重复补写。DeepEP Fused MoE 等明确待写内容另立课程任务。

## 内容标准

逐步给正文统一增加：本课目标、先修知识、核心结论、一个贯穿例子、源码与版本、限制、练习及答案。深入源码折叠或分章，不能通过删去平台条件来制造简洁。

实验统一区分“数学模拟”“源码结构核对”“真实设备运行”。所有性能结论都需要具体环境、工作负载和对比方法。`platformScope` 与文档存在状态不能用于生成“支持所有后端”“已验证可部署”等结论。
