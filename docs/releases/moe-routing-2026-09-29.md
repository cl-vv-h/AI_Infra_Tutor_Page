## Withdrawal

On a clean release checkout, fetch and inspect the current main branch, retaining
any later news and user commits. Withdraw only this increment, newest first:

```sh
git revert --no-edit 3bc6a4c7fc026b998052d66347685cc750b22824
git revert --no-edit 5a8471f87e93abf315f7d1206f83a82ce08a91d3
```

If either command conflicts, stop and preserve the conflict for review; do not
reset main, restore the entire repository or force-push. Historical release
notes can remain. Run the checks and publish the resulting revert commits before
claiming production has been rolled back. Re-enabling requires another verified
release; reverting the actual revert commits preserves intervening changes.

Alternatively set `config/moe-routing.json` to `{"enabled":false}`, then rebuild
and deploy. This gates the sandbox route and model-navigation entry only. It is
not an instantaneous remote switch and does not delete local browser data.
The static companion diagram is an explanatory document, not a gated calculator.
