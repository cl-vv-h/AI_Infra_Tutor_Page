# 模型知识体系与页面整理

日期：2026-09-21。

## 内容结构

| 层级 | 专题 |
| --- | --- |
| 模型结构 | 张量与数据流、Attention 与状态、Dense 与 MoE |
| 执行与存储 | 并行策略、精度与量化、内存账本 |
| 服务与性能 | 调度与请求生命周期、Kernel 与执行图、性能指标与验证 |

每个专题包含三个核心概念，各自提供定义、关系式和适用范围。先修链接构成有向无环关系，课程与模型实例连接已有内容；不另建一套数值计算逻辑。知识体系、模型目录与对比实验共用导航，原模型路由及分享参数保持兼容。

## 展示整理

- 首页使用主题标题与内容分类，删除宣传式导语。
- 模型导览改为模块知识卡，移除问题、预测与答案揭示流程。
- V4.1 八个专题使用紧凑选择器，内容随当前实验参数直接更新。
- 模型、缓存和权重工具采用陈述式标题；新闻站内研读指南使用分析维度与概念定义。
- 知识页采用统一字体层级、公式区域与高对比辅助文字；桌面侧栏和移动选择器分别布局。

原始课程正文与第三方新闻标题保留来源内容；此次文案整理针对站内导航、知识索引及交互说明，不声称改写全部上游资料。

## 验证与边界

`test:models:knowledge` 检查九个专题、先修关系、课程目标和有效模型参数；静态渲染覆盖知识首页、全部专题、无效路由、132 个模型工作区、对比与 DPA 页面。现有模型、混合精度、专家打包、Kimi 加载及新闻测试保持有效。

浏览器回归覆盖 360、390、768、1440px 的布局、导航、专题切换和已有数值工具交互。V4.1 参数联动测试先确认 world 与 rank 上限更新，再验证尾卡 Engram 补齐，避免依赖旧“揭示答案”点击带来的偶然等待。

本地生产构建验收通过：159 项模型单元测试、28 项打包/混合精度/加载审计测试、50 项新闻测试、4 项知识体系测试及对应渲染回归；真实 Chrome 完成 351 次视口宽度检查，无页面运行时错误。类型检查、lint 和生产构建通过，276 份课程正文保持独立分包；人工检查了知识首页、专题及门户的移动/桌面截图。

PP/SP/CP、服务调度及性能测量在知识体系中提供概念和课程入口，不宣称新增硬件模拟或真实推理结果。没有新增模型 API、凭证、个人资料或收藏上传；周报机制不变。
