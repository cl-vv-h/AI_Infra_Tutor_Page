# 热点榜、分布与关注

`#/news/events` 默认打开热点榜。旧的 `?event=...&step=...` 深链接保持原有人工核对阅读器；`?mode=reviewed` 是独立入口。没有新增首页模块。

## 数据与排序

- 39 个公共 feed；新增 BBC World / Business、DW、Al Jazeera、CNA Business。来源国家描述发布机构所在地，不代表事件发生地、民意或独立证实。
- `fetch-news.mjs` 在每日精选数量限制**之前**生成 `src/data/news/hotspots.json`，只保留标题、链接、发布时间、发布方、来源地区、首次／最近收录时间，不抓正文、不调用模型、不读取密钥。
- 候选集合滚动保留 30 天。首次运行可能回填 feed 内历史条目；统计不是完整历史，也不是全网热搜。短暂失败保留窗口内旧报道，来源状态公开。数据坏格式／版本不符时采集失败，不覆盖为假成功。写入使用同目录临时文件与 rename。
- 每 4 小时（UTC 的 00:30、04:30、08:30、12:30、16:30、20:30）计划采集并发布。Actions 可以延迟；展示真实采集时间，超过 12 小时显示陈旧提示。发布构建不能刷新采集时间。
- 算法 `news-hotspots/1`：近 24 / 72 / 168 小时，按 URL 去重，标准化后相同标题跨来源只获一次计分。每条权重 `2^(-age_hours / 24)`；同发布集团最多取 3 条最高权重，求和 × 10，四舍五入至一位小数。既有每日 `importanceScore` 不参与热度。分数不是百分数，没有 100 分上限。
- 可切换最新发布、发布方覆盖排序。地区筛选只选择有相应来源的热点，**不重新计算局部热度**；界面有明确说明。
- 公开有序字面规则生成稳定主题；每条归入首个匹配主题。这是主题聚合，不声称是一件事件，也不自动把报道升级为已核实节点。
- 未命中主题的同板块标题，去停用词后至少 3 词相同，且占较长标题有效词数至少 60%，才与一个种子标题合并。无传递式合并；人工待核对。全 30 天语料先分组再裁时间窗口，避免切换窗口更改组 ID；种子离开保留窗口后 ID 仍可能改变。不同措辞可能漏分，相似措辞可能误分，不能推断因果或真实性。
- 无法聚合的单篇仍进入榜单。主题宽窄、语言、信源覆盖会影响排名；不发布“全网热度增长率”。

## 分布与追踪

榜单旁展示四板块 URL 去重报道数、来源地区数量；七日热力表按 UTC 发布日期计数。手机使用“查看热点分布”折叠按钮，不把图表或说明推到长列表底部。今日不是完整自然日，历史柱高可能来自回填，不当作升温结论。

主题详情显示当前窗口分数、全部保留报道的发布时间线、每日数量、发布方与关联规则。没有分析新闻正文、提炼未经核对的结论。旧人工核对页面保持来源、核对日期与声明类别。

只有具有稳定规则的主题支持关注。自动相似标题／单篇线索可以通过链接回看，不承诺其长期追踪身份稳定。

`ai-infra-hotspot-follows-v1` 独立 localStorage 键，版本 1，最多 50 条。Web Locks 下重新读取、修改、写入并回读校验；没有锁能力则明确拒绝写入。支持跨标签页 storage 事件同步；拒绝、配额不足、损坏格式不会显示虚假成功或静默覆盖。保留已退休主题的记录，允许手动取消关注。与旧阅读清单、IndexedDB 方案库无耦合。

关注时以当前**采集时间**设已读边界，此后 `firstSeenAt` 更晚的报道显示新收录。进入详情不自动清空；用户显式标记已读。旧快照不会让已读边界倒退。标记新收录不是认定“刚发生”，不检测正文更新。只保存在当前浏览器，不上传、不跨设备同步、不发系统通知。

## 验证与撤回

- `node --test tests/news-hotspots.test.mjs`：保留／回填／版本、URL、时间、计分、集团上限、标题去重、谨慎聚类、分布一致性、关注写入与失败。
- `node tests/news-hotspots-browser.mjs`：360 / 390 / 768 / 1440px；真实排序、筛选、分布、URL、键盘、刷新返回、关注、跨标签页、新收录／已读、拒绝／损坏存储、陈旧快照与懒加载恢复。
- 原 `tests/news-events-browser.mjs` 继续覆盖四个人工核对主题及其深链接；热点浏览器测试纳入部署阻断检查。
- `config/news-hotspots.json` 关闭后重新构建，默认路由回到原阅读器；**不是即时远程关闭**。不删除本机关注或服务端公共语料。
- 数据采集提交先于功能提交，独立保存；撤回功能只 `git revert <feature-SHA>`，保留最新新闻。若出现冲突停止并保留现场，不强推或恢复整仓。精确 SHA 与演练见本轮发布记录。
